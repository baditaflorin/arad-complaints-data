# Source data and reuse

The scraper code is offered under the repository's MIT licence. That licence does
not apply to the municipality's source data, text, photographs, logos, or maps.

The MyArad public map and its unauthenticated JSON feed are accessible to anyone.
No explicit upstream licence permitting unrestricted reuse and redistribution was
identified during this extraction. Treat the supplied projection as public-source
data with reuse terms pending clarification, rather than claiming CC0/CC BY for
material we do not own.

The reusable output contains only public issue identifiers, controlled categories,
status, submission date, original reported map position, and provenance. It
deliberately excludes every complaint message and response, reporter field, photo,
attachment, and map-provider key.

Coordinate accuracy is that of a user-reported marker in the source; it has not
been independently verified. No geocoder or map tile data was used to generate
coordinates.
